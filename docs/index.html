Selector Preference

Five PrismaUI overlay sketches for the same settings file. The working draft is mockup 1: compact card by default, with a toggle that opens a preview of what this processing of the speaker-selector prompt would contain. Mockup 4 is that same overlay with the preview already open. The others are still here if you want to steal a layout idea. Slider positions stick in this browser.

Working draft

Compact card + selector prompt preview

Small panel on the left. Open the preview when you want to see the constructed selector prompt, including a fake Bannered Mare log, nearby people, summaries, and Interjection lines.
Mockup 2

Named buttons, no track

No slider track. Each preference is a row of named buttons, because each position is a different instruction paragraph, not a 0–100 number turned into vague prose.
Mockup 3

Columns by who just spoke

You and a townsperson / two NPCs talking / idle as three cards. Each column shows what 0 means and which sliders apply.
Same overlay

Preview already open

Identical to the working draft, just starts with the preview showing so you do not have to hunt for the toggle.
Mockup 5

Thin HUD

Bottom-left strip, low chrome, meant to stay up while you talk. Closest to pressing a hotkey, changing a slider, and keeping playing.
