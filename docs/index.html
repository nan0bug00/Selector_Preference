Selector Preference

Five PrismaUI overlay sketches for the same settings file. The working draft is mockup 1: compact card by default, with a toggle that opens the compiled letter. Mockup 4 is that same overlay with the letter already open. The others are still here if you want to steal a layout idea. Notch choices stick in this browser.

Working draft

Compact card + letter toggle

Small panel on the right. Open the letter preview when you want to see what this tick would send, including a fake Bannered Mare log, nearby people, summaries, and Interjection lines.
Mockup 2

Word notches

No slider track. Each preference is a row of named buttons, because the packets are discrete, not 0–100 prose.
Mockup 3

Situation columns

Your turn / room continues / idle as three cards. Each column shows what 0 means and which sliders feed that letter.
Same overlay

Letter already open

Identical to the working draft, just starts with the preview showing so you do not have to hunt for the toggle.
Mockup 5

Thin HUD

Bottom-left strip, low chrome, meant to stay up while you talk. Closest to “hotkey, tweak, keep playing.”
